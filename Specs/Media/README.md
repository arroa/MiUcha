# Media

Imágenes que necesitan Funcional, Arquitectura, DataBase o Integration.

El archivo se nombra por lo que muestra (`planta-baja.png`) y el documento lo cita así:

```markdown
![Planta baja](./Media/planta-baja.png)
```

Desde un documento en esta misma carpeta `Specs`, la ruta es `./Media/nombre.png`.
